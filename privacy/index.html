Privacy Policy

Fleetpad is local software. It does not upload your folders, logs, or process stats.

Last updated: October 16, 2026

This Privacy Policy describes how the Fleetpad desktop application, the website, and update downloads (together, the "Software") handle information.

The short version: The desktop app runs on your computer. It does not send us your project paths, file contents, terminal output, or CPU and memory stats — there is no Fleetpad sign-in. We do not sell personal information. The app's only routine contact with infrastructure we publish is an update check and, when needed, a signed app-bundle download.

1. We do not collect your project data

We do not collect, receive, or store:

  • User accounts, email addresses, or login credentials for Fleetpad (the app has none)
  • Folder paths, file contents, package manifests, or cache listings
  • Process lists, live logs, CPU samples, or memory stats
  • Analytics or telemetry about how you use the desktop app

Those materials stay on your device. We are not in that path.

What Where it lives Do we receive it?
Workspaces, project lists, pins Your device No
Dev-server logs and process stats Your device No
Cache cleanup (files you delete) Your device No
Update check / bundle download Public file host (static files) No project contents

2. The only network we run for the app: updates

We do not run a Fleetpad backend that your projects talk to.

When the desktop app launches, it may request a public manifest from https://fleetpad-bundles.strum.workers.dev and, if a newer signed bundle is available, download that zip. That is a static file download. It does not include your folders, logs, or process stats.

The files are served as ordinary HTTPS downloads. Like any file download, the host may see connection metadata (such as IP address, user agent, and that a particular file was requested) in order to deliver the file. We do not use update checks to identify you or attach activity to an account — there is no account.

Without a network connection, the app can keep using a bundle already on your machine.

3. The website

This website is a marketing site. It does not require an account. Download links redirect to the current installer file. We do not set an analytics cookie on these pages.

4. Children

The Software is not directed at children under 13, and we do not knowingly collect personal information from them.

5. Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
